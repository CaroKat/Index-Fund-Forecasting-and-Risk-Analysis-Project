# Risk-Forecasting-Index-Fund-Project

This quick project aims to practice classical multivariate data analysis and choose the best forecasting model. I aim to use both econometric and statistical practices. 

- Create a return variable
- Control for economic/historical shocks within the data -- given the size of the dataset, we can assume that shocks (outliers) would not affect the dataset too much, assuming we test for normality, etc.
- Create an 80/20 train/test split and use OLS and other models
